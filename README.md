# fed-casamento-angular

Frontend Angular 22 do Marketplace de Casamentos.

## Pré-requisitos

- Node.js 24+
- npm
- Backend rodando em `http://127.0.0.1:3000`

## Executar

```powershell
cd C:\Users\andre\IdeaProjects\fed-casamento-angular
npm install
npm start -- --port 4201
```

Acesse: `http://127.0.0.1:4201`

## Build

```powershell
npm run build
```

## Testes

```powershell
npm run test -- --watch=false
```
